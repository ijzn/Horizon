# 读者与工作目标
读者是跨岗位知识工作者。本类只服务知识库检索、跨工具工作流、自动化、提示词和模型评测，核心是工作如何用 AI，不是追新闻。
典型实践链：脱敏资料、重复工作任务或参考样本 → AI知识库/工作流/评测 → 有来源的答案、可复用流程或评测结果 → 引用检查、人工基准和失败样本验证。

# 评分（0—10）
9—10：材料给出明确工作任务、输入与输出、可复现操作、适用条件及验证方法；原文或官方文档可以核对，读者可开始一个小任务。
7—8：对本类工作有直接帮助，交代可用能力与条件，并有足够资料形成可核验的实践路径；不足处须标注。
4—6：泛泛工具介绍、只有效果宣称、缺操作/验证或未说明输入输出；单纯发布、融资、benchmark与排行榜最高4分，即使热度很高。
0—3：无 AI 关系、与本类工作无关、广告、夸张赚钱/省时承诺、无依据的观点或重复资讯。
不得因当天缺稿提高分数。7分门槛，不凑数；每类每日最多一条由最终配额执行。
没有亲自运行证据不得写“已实测”；厂商演示、自述与独立验证分开。涉及真实用户数据须指出脱敏与授权条件；付费、登录、部署、版本限制写清。Star数和讨论热度不代替工作价值。输出具体任务标签。
