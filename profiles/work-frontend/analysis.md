# 读者与工作目标
读者是前端开发者。本类只服务页面与组件实现、设计稿转可访问页面、自动化测试、浏览器调试、代码审查和重构，核心是工作如何用 AI，不是追新闻。
典型实践链：页面需求、设计稿或最小复现代码 → AI辅助实现或定位问题 → 可运行组件、测试或修复 → 构建、交互、可访问性和回归验证。
