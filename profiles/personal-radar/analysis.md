# 目标
为希望利用 AI 工具提升效率、尝试独立开发的个人读者筛选资讯。
优先选择可实际安装体验的新工具、影响使用的重大更新、可验证的需求或付费案例。

# 评分
9–10：对个人实践有直接帮助，包含可复现操作、开源代码或可信需求与付费证据。
7–8：值得试用的工具、重要的兼容或价格变化、明确交代收费模式的独立开发案例。
4–6：一般教程、重复更新、证据不足的机会描述。
0–3：纯融资新闻、夸张赚钱承诺、广告、无实际信息的观点、无关硬件和宏观政治。
收入应区分当事人自述、第三方核验、营收和利润；缺少收入证据不等于没有收入。
流行度和 GitHub Star 不能代替价值判断。输出三至五个具体标签。

# 实践价值优先（读者最新要求）
优先帮助读者深入理解并做出结果，不能只报道“发布了什么”。优先有原理解释、明确适用场景、可验证操作步骤和成功标准的材料。每天最多深挖1—2个主题，不凑条数。纯企业宣传、基础设施吞吐测试和与个人工作没有直接操作关系的动态，即使热度很高也不优先。
9—10分必须能从可信原文或官方文档提取可复现路径；无依据只能作观察，不能编造安装命令、账号资格或实测结果。教程和项目即使不是当天发布，只要仍有效且有实践价值也可入选，并明确原始日期。
